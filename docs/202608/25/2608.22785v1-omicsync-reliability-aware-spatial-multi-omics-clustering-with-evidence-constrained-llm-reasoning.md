## 摘要
空间多组学技术能够在每个组织点位联合分析基因表达、表面蛋白和组织学特征，然而大多数空间结构域发现方法仅提供聚类分配结果，未指明分配的可靠性、模态贡献或领域决策应受信任的原因。我们提出OmicSync，一个可靠性感知的空间多组学框架，将无监督聚类与基于模型逐点信号的证据约束LLM推理相结合，这些信号包括分配置信度、认知路由不确定性和模态路由权重。这些信号被转化为结构化证据字典，用于生成标准、逐步、反事实、对比和聚焦不确定性的解释。OmicSync集成了KAN-GCN骨干网络，包含空间编码、跨模态融合、不确定性感知路由、细胞类型监督和缺失模态插补。我们进一步引入OmicSync-R，通过自动计算推理质量分数作为REINFORCE奖励，在不通过语言模型反向传播的情况下使推理连贯性塑造潜在结构，从而闭环推理-聚类循环。在四个10x CytAssist FFPE空间蛋白质组学基准上，OmicSync在人类扁桃体（1.44）、胶质母细胞瘤（1.78）和扁桃体附加组（1.22）上取得最佳平均排名，在人类乳腺癌（2.33）上排名第二。OmicSync-R进一步将人类乳腺癌的ARI从45.73提升至46.72，并在九项聚类指标中的六项上优于现有方法。综上，OmicSync和OmicSync-R在证据约束推理的引导下，实现可靠性感知、点级可审计的空间域发现。

## Abstract
Spatial multi-omics technologies jointly profile gene expression, surface proteins, and histology at each tissue spot, yet most spatial domain discovery methods provide only cluster assignments, without indicating assignment reliability, modality contributions, or why a domain decision should be trusted. We present OmicSync, a reliability-aware spatial multi-omics framework that couples unsupervised domain clustering with evidence-constrained LLM reasoning using model-derived per-spot signals, including assignment confidence, epistemic routing uncertainty, and modality-routing weights. These signals are converted into structured evidence dictionaries and used to generate standard, stepwise, counterfactual, contrastive, and uncertainty-focused explanations. OmicSync integrates a KAN-GCN backbone with spatial encoding, cross-modal fusion, uncertainty-aware routing, cell-type supervision, and missing-modality imputation. We further introduce OmicSync-R, which closes the reasoning-clustering loop by using automatically computed reasoning-quality scores as REINFORCE rewards, allowing reasoning coherence to shape the latent structure without backpropagating through the language model. Across four 10x CytAssist FFPE spatial proteomics benchmarks, OmicSync achieves the best average rank on Human Tonsil (1.44), Glioblastoma (1.78), and Tonsil Add-on (1.22), and second-best on Human Breast Cancer (2.33). OmicSync-R further improves ARI on Human Breast Cancer from 45.73 to 46.72 and outperforms existing methods on six of nine clustering metrics. Together, OmicSync and OmicSync-R enable reliability-aware, spot-level auditable spatial domain discovery guided by evidence-constrained reasoning.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：空间多组学技术（如 10x Genomics CytAssist FFPE）能够同时在每个组织斑点（spot）上检测基因表达（RNA）、表面蛋白（ADT）和组织学图像（H&E），但现有的大多数空间域发现方法只返回一个"扁平"的聚类分区，即只告诉用户"每个斑点属于哪个域"，却无法回答三个关键问题：
  - 哪些聚类分配结果是**可靠**的？
  - 哪些模态（RNA/ADT/组织学）**主导**了每个决策？
  - 为什么某个斑点被分配到特定组织域（即决策的**依据**是什么）？
- **实际后果**：下游分析（如差异表达分析、配体-受体推断、细胞状态映射）将所有斑点分配一视同仁地对待，边界斑点或数据质量退化的斑点可能传播聚类错误，导致错误的生物学结论。
- **方法缺口**：现有方法（GROVER、MISO、SpatialGlue、COSMOS）虽然各有优势（KAN图卷积、多尺度整合、跨模态注意力、对比多视图学习），但均缺乏对聚类分配进行可靠性量化与解释的能力。可解释性方法（SHAP、注意力可视化）提供的是特征归因而非基于内部可靠性信号的逐点聚类解释；LLM虽已用于单细胞生物学，但尚未与空间聚类模型通过结构化证据耦合生成可靠性感知的解释。
- **整体含义**：需要一个"可靠性感知、逐点可审计、证据约束推理"的空间域发现框架，使聚类输出不仅可分区，还可被理解、可被信任、可被审计。

## 2. 提出的方法论

### 2.1 核心思想

OmicSync 将无监督域聚类与证据约束的 LLM 推理耦合：首先从聚类模型提取三类核心逐点可靠性信号（软分配置信度、认知路由不确定性、模态路由权重），将这些信号与特征级和空间邻居证据组装成结构化证据字典，再由 LLM 根据该字典生成多种策略的自然语言可靠性报告。OmicSync-R 进一步通过 REINFORCE 策略梯度将自动计算的推理质量分数作为奖励反馈到聚类训练中，形成"推理-聚类闭环"。

### 2.2 整体架构

OmicSync 包含以下关键组件：

1. **预处理管道**：
   - RNA：库大小归一化（10⁴）+ log(1+x) 变换 → 选取 3,000 个高变基因 → PCA 降至 ≤49 维
   - ADT：中心化对数比（CLR）归一化 → PCA 降至 ≤49 维
   - 组织学：提取 224×224 H&E 图像块 → 经过病理基础模型 UNI 得到 1,024 维 CLS 嵌入 → L2 归一化
   - 空间坐标用于构建空间邻接矩阵和特征邻接矩阵

2. **SpatialPositionEncoder**：使用正弦 2-D 位置编码，将空间位置信息注入各模态特征，使分子谱相同但位置不同的斑点（如生发中心边缘 vs 中心）获得可区分的表示。

3. **KAN-GCN 编码器 + 模态内注意力（骨干网络）**：每个模态分别对空间邻接矩阵和特征邻接矩阵施加共享权重的 KAN-GCN，通过模态内注意力层自适应融合空间与特征证据。该骨干沿用 GROVER 设计并保持不变，以隔离新组件的贡献。

4. **CrossModalTransformer**：将三个模态的嵌入堆叠成 token 序列，通过多头自注意力 Transformer（4 头、2 层）加上可学习的模态类型嵌入，使同一斑点的 RNA、ADT、组织学 token 在融合前能相互关注，实现跨模态上下文增强。

5. **UncertaintyMoE（不确定性感知混合专家路由）**：
   - 门控网络在 MC-Dropout 下进行 T=10 次随机采样
   - 均值门控向量 ḡᵢ ∈ [0,1]³ 表示模态路由权重（RNA/ADT/组织学的相对贡献）
   - 路由不确定性 uᵢ = Σₘ Var(gᵢ,ₘ,ₜ) 衡量模态选择在随机采样下的稳定性
   - 低于阈值 τ=0.3 的专家被剪枝，剩余权重重新归一化后加权融合

6. **ClusteringHead（聚类头）**：基于 Student's t 核的软分配，生成软分配矩阵 Q；聚类损失为自锐化的 KL 散度；质心在 50 epoch 热启动阶段通过 k-means 初始化。

7. **CellTypeHead 和 ImputationHeads**：前者提供半监督的细胞类型正则化（使用 RNA 的 Leiden 伪标签，70% 训练/30% 留出）；后者通过对随机掩码的模态特征进行重建，使表示对缺失模态具有鲁棒性。

### 2.3 训练目标

总损失为：
L = λᵣL_recon + λc(t)L_contrast + λₖL_cluster + λ_bL_celltype + λₚL_impute + λ_uL_unc

其中关键创新：

- **自适应空间排除半径（adaptive nhops）**：根据组织同质性动态调整对比学习中的排除半径——同质组织（如扁桃体，平均邻居相似度 >0.6）使用 nhops=2，异质组织（如乳腺癌）使用 nhops=1
- **对比损失权重衰减**：前半训练保持基础权重，后半线性衰减至 1/3，使早期强调空间一致性、后期强调聚类与重构
- **半监督细胞类型正则化**：以 Leiden 伪标签作为辅助分类目标，提供结构先验

### 2.4 Task C：证据约束推理

- 为每个斑点组装证据字典，包含：预测域、分配置信度 cᵢ、亚军域及置信度边际 Δᵢ、模态路由向量 ḡᵢ、路由不确定性 uᵢ、主导模态的 top 证据特征、5 最近邻邻域组成
- 五种推理策略：
  - **标准**：证据直接到结论
  - **逐步**：五步结构化推理（分子证据 → 模态加权理由 → 空间上下文 → 置信度与不确定性解释 → 最终结论）
  - **反事实**：回答"若无此证据/模态/邻域变化，预测是否仍成立"
  - **对比**：为何选择该域而非亚军域
  - **不确定性**：根据不确定性层级判断是否可信任
- LLM 骨干使用 Llama-3.3-70B（通过 Groq API），系统提示严格约束模型只能使用提供的证据，不得引入未提供的基因名、蛋白名、引用或生物学主张
- 三个自动评估指标：**接地率（GR）**、**置信度对齐（CA）**、**空间一致性（SC）**

### 2.5 OmicSync-R：REINFORCE 推理引导训练

- 从软分配分布采样候选域标签 → 组装条件证据字典 → LLM 生成解释 → 计算合成奖励 Rᵢ = 0.5·GR + 0.3·CA + 0.2·SC
- 使用 EMA 基线 bₜ 降低梯度方差（α=0.9，b₀=0.5）
- REINFORCE 损失：L_reinforce = −(1/|S_R|)Σ sg(Rᵢ − bₜ) log qᵢ,ₐᵢ（sg 表示停止梯度）
- 每 25 epoch 在热启动后采样 10 个域分层斑点，λ_R=0.02 远小于聚类权重，保证几何域分离仍是主目标

## 6. 主要结论与发现

### 6.1 聚类性能

- OmicSync 在 **Human Tonsil（平均排名 1.44）**、**Human Glioblastoma（1.78）** 和 **Tonsil Add-on（1.22）** 上取得最佳平均排名，在 **Human Breast Cancer** 上排名第二（2.33）
- 在 **全部四个数据集上取得最佳 ARI**（46.81、45.73、45.74、53.80），且方差极小
- CHI 值以极大优势超过基线（如胶质母细胞瘤 7,904 vs. 基线最优 1,430），表明学习到的潜在表示具有更强的簇分离度和紧凑性
- 最大 ARI 提升出现在扁桃体附加抗体数据集（53.80 vs. GROVER 46.5），表明更丰富的抗体面板可被 CrossModalTransformer 和不确定性 MoE 有效利用
- 在 Human Tonsil 上存在 Purity 与 ARI 的权衡：OmicSync Purity（57.71）低于 GROVER（69.4），但 CHI、SilC、DBI 更优，说明两个指标捕捉聚类质量的不同维度

### 6.2 可靠性信号一致性

- 高置信度斑点（≥0.35）的平均路由不确定性（0.034）约为低置信度斑点（<0.20）的 1/3.3（0.111）
- 高置信度斑点的空间邻域同质性（75.6%）比低置信度斑点（60.0%）高约 26%
- 置信度与路由不确定性呈中等程度负相关（r = −0.42，p < 0.01），两者相关但不等同——置信度衡量分配分布的锐度，路由不确定性衡量模态选择权重的稳定性

### 6.3 推理质量

- **Stepwise 策略**取得最强联合性能（GR=1.00、CA=1.00、SC=0.975），结构化五步格式鼓励模型显式引用所有证据类型
- 基于证据的提示设计总体有效地将生成解释锚定到提供的标记证据上（多数策略 GR > 0.94）
- Uncertainty 策略的 GR 极低（0.074）是设计使然（聚焦不确定性而非标记证据），但 CA 完美（1.00）

### 6.4 OmicSync-R 效果

- 在乳腺癌上 ARI 从 45.73 提升至 46.72（+0.99），FMI +1.79、AMI +2.07、Jaccard +3.08、SilC +1.28，DBI 从 178.76 降至 165.30
- 在 9 个指标中 6 个超过 GROVER（ARI、CHI、AMI、Jaccard、SilC、Purity）
- 推理奖励轨迹显示：接地率始终很高（平均 ≈0.98）；置信度对齐从初期 0.37 提升至峰值 0.775；空间一致性最不稳定，后期有所衰退
- **k 敏感性**是显著问题：OmicSync-R 在 k=10 时 ARI=46.72，但在 k=6–9 时仅 23.68–27.77

### 6.5 模态路由发现（探索性）

- 高置信度斑点中 RNA 为主导模态的占 7/9；低置信度斑点中图像和 ADT 证据更常主导
- 扁桃体数据集中 ADT 主导与 B 细胞相关表面标记（CD19、CD20、IgD）关联
- 附加抗体面板将扁桃体的平均路由不确定性从 0.088 降至 0.053（1.7 倍降低），量化了更高通量蛋白检测对可靠域分配的益处
