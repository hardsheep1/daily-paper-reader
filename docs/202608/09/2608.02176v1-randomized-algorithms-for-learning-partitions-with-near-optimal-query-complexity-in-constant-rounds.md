## 摘要
我们研究了使用配对查询学习一个n元素宇宙的隐藏划分$\mathcal{P}$的轮复杂度：配对查询PAIR($x,y$)告诉我们$x$和$y$是否属于划分的同一部分。虽然使用基本算法可以轻松地以$n|\mathcal{P}|$次查询学习，且该查询复杂度是最优的，但该基本算法高度串行。Black、Mazumdar和Saha [COLT 2025]最近在已知$\mathcal{P}$的部分数量时给出了紧的确定性轮/查询权衡。特别地，他们证明$\Theta(\log\log n)$轮对于将查询次数限制到$n|\mathcal{P}|$既是充分的也是必要的。他们将证明随机化下界留作开放方向。我们表明随机化极大地改变了图景。当部分数量$k = |\mathcal{P}|$已知时，我们给出一个简单的3轮随机算法，以高概率使用$O(nk\log n)$次查询，并证明2轮需要$\Omega(n^{4/3}k^{2/3})$次查询——与确定性算法相同。我们还研究了部分数量未知的更一般设置。在这种情况下，我们给出一个4轮随机算法，以高概率使用$O(n|\mathcal P|\log^2 n)$次查询，并证明3轮无法实现近最优查询复杂度。此外，我们在此情形下展示了随机算法与确定性算法之间更大的分离：对于后者，$\Theta(\log n/\log\log n)$轮对于获得近最优查询复杂度既是必要的也是充分的。

## Abstract
We study the round complexity of learning a hidden partition $\mathcal{P}$ of an $n$-element universe using PAIR queries: PAIR($x,y$) tells us whether $x$ and $y$ belong to the same part of the partition or not. While it is easy to learn using $n|\mathcal{P}|$ queries using a basic algorithm and this query complexity is optimal, this basic algorithm is highly sequential. Black, Mazumdar, and Saha [COLT 2025] recently gave tight deterministic round/query tradeoffs when the number of parts of $\mathcal{P}$ is known. In particular they prove $Θ(\log\log n)$ rounds are sufficient and necessary to limit the number of queries to $n|\mathcal{P}|$. They leave proving a randomized lower bound as an open direction.   We show that randomization dramatically changes the picture. When the number of parts $k = |\mathcal{P}|$ is known, we give a simple 3-round randomized algorithm using $O(nk\log n)$ queries with high probability, and prove that 2 rounds require $Ω(n^{4/3}k^{2/3})$ queries -- the same as deterministic algorithms. We also study a more general setting where the number of parts is unknown. In this case, we give a 4-round randomized algorithm using $O(n|\mathcal P|\log^2 n)$ queries with high probability, and prove that 3-rounds cannot achieve near-optimal query complexity. Furthermore, we show an even bigger separation in this regime between randomized and deterministic algorithms: for the latter, $Θ(\log n/\log\log n)$ rounds are necessary and sufficient to obtain near-optimal query complexity.

## 1. 论文的核心问题与整体含义

- **研究背景**：论文研究“隐藏划分学习”问题。给定一个 $n$ 元素宇宙 $U$ 和一个隐藏划分 $\mathcal{P}$，学习算法只能通过 PAIR 查询（询问两个元素是否属于同一部分）来恢复划分。
- **基本事实**：存在一个简单算法，用 $n|\mathcal{P}|$ 次查询即可学习任意划分，且该查询复杂度是信息论最优的。但该算法高度串行，需要约 $|\mathcal{P}|-1$ 轮自适应查询。
- **核心问题**：在保持（近）最优查询复杂度的前提下，算法至少需要多少**轮**查询？换言之，轮复杂度与查询复杂度之间如何权衡？
- **已有工作**：Black、Mazumdar 和 Saha（BMS, COLT 2025）给出了确定性算法的紧结果：已知划分数量 $k$ 时，$\Theta(\log\log n)$ 轮是实现 $O(nk)$ 查询的必要且充分条件。他们将“证明随机化下界”留作开放问题。
- **本文回答**：随机化**根本性地改变**了这一权衡：
  - 已知 $k$ 时，存在 **3 轮**随机算法，以高概率只用 $O(nk\log n)$ 查询；而 **2 轮**随机算法与确定性算法一样，需要 $\Omega(n^{4/3}k^{2/3})$ 查询。
  - 未知 $k$ 时，存在 **4 轮**随机算法，以高概率用 $O(n|\mathcal{P}|\log^2 n)$ 查询；而 3 轮随机算法无法达到近最优查询复杂度。
  - 对于确定性算法，未知 $k$ 时实现近最优查询需要 $\Theta(\log n/\log\log n)$ 轮，远高于已知 $k$ 时的 $\Theta(\log\log n)$ 轮。
- **整体含义**：本文回答了 BMS 的开放问题，并首次系统研究了未知划分数量设置下的轮数/查询权衡；结果表明随机化可以在常数轮内获得近乎最优的查询复杂度，与确定性算法形成指数级/超对数级的分离。

## 2. 方法论

### 2.1 核心思想

- **随机采样构造网（net）**：随机采样 $T$ 个点可以高概率命中所有大小 $\ge n/T$ 的划分部分。据此可以先用少量采样点“探测”出大部分划分结构。
- **已知 $k$ 的 3 轮算法（Algorithm 1）**：
  1. **第 1 轮**：随机采样 $R$（大小 $O(\sqrt{nk}\log n)$），对 $R$ 内所有点对做 PAIR 查询，恢复 $R$ 的局部划分，并选取每部分的一个代表。
  2. **第 2 轮**：将每个代表与宇宙中所有其余点做 PAIR 查询，从而完整恢复所有“大”部分（大小 $\ge \sqrt{n\log n/k}$）。
  3. **第 3 轮**：对剩余未分类点集合 $P'$ 做全对查询。可以证明 $|P'|\le \sqrt{nk}\log n$（高概率），因此总查询为 $O(nk\log n)$。
- **未知 $k$ 的 4 轮算法（Algorithm 2）**：
  - 第 1 轮用 $\tilde O(n)$ 次查询构造一个**可用下界** $k^*$（可能远小于真实 $k$），然后对后续 3 轮调用 Algorithm 1。
  - 关键观察：不需要精确估计 $k$。对于每个幂次 $s=2^i$，随机采样 $O(s\log n)$ 个点，对每个点再做 $n/s$ 次 PAIR 查询，通过“恰好一个 YES”判断该点所在部分大小是否约为 $s$。据此找到最小的“有用” $s$，从而得到 $k^*$。
  - 文章证明 $k^*\le k$ 高概率成立，并且即使 $k^*\ll k$，最后剩余的未分类点数也能被限制在 $\tilde O(\sqrt{nk})$，从而总查询为 $O(n|\mathcal P|\log^2 n)$。

### 2.2 下界技术

- **已知 $k$ 的 2 轮下界（Section 3.1）**：
  - 构造一个分布 $\mathcal D$：将宇宙随机分成 $U_1,\dots,U_k$，每个元素独立以 $l^{-1/3}$ 概率进入“红色集合” $R_i$；再从 $R$ 中均匀采样一对 $(a,b)$。
  - 以等概率输出 DOUBLETON 划分（$\{a,b\}$ 单独成一部分）或 SINGLETON 划分（$\{a\},\{b\}$ 分别成一部分）。
  - 关键：如果算法没有查询到 $(a,b)$，就无法区分两种划分。第 1 轮查询答案几乎不含 $(a,b)$ 信息；第 2 轮即使结合第 1 轮答案，$(a,b)$ 仍在巨大集合中近乎均匀分布，因此 $o(n^{4/3}k^{2/3})$ 次查询命中 $(a,b)$ 的概率为 $o(1)$。
- **未知 $k$ 的 3 轮下界（Section 3.2）**：
  - 以概率 $1/2$ 输出平凡划分（单一部分），以概率 $1/2$ 输出上述硬分布（$k=\omega(n^{2/3})$）。
  - 平凡划分迫使第 1 轮查询 $\le \tilde O(n^{4/3})$。随后证明第 1、2 轮无法显著缩减 $(a,b)$ 的不确定性，第 3 轮仍需 $\Omega(n^{4/3}k^{2/3})$ 查询。
- **确定性算法下界（Section 4.2）**：
  - 使用对抗式论证，通过图染色数上界控制算法能推断出的部分数下界，证明未知 $k$ 时实现 $O(nk\log^c n)$ 查询必须 $\Omega(\log n/\log\log n)$ 轮。

### 2.3 弱子集查询的扩展（Section 5）

- 将随机算法扩展到“弱子集查询”（给定子集 $S$，返回 $S$ 覆盖的划分部分数），查询数为 $O(nk/s^2)$，其中 $s$ 为查询子集大小上限。
- 已知 $k$ 时用 3 轮，未知 $k$ 时用 4 轮，均以高概率完成学习。

## 6. 主要结论与发现

| 设置 | 算法轮数 | 查询复杂度 | 下界 |
|------|----------|------------|------|
| 已知 $k$，随机化 | 3 轮 | $O(nk\log n)$（whp） | 2 轮需 $\Omega(n^{4/3}k^{2/3})$ |
| 未知 $k$，随机化 | 4 轮 | $O(n|\mathcal P|\log^2 n)$（whp） | 3 轮无法近最优（需 $\Omega(n^{4/3}|\mathcal P|^{2/3})$） |
| 未知 $k$，确定性 | $\Theta(\log n/\log\log n)$ 轮 | $\tilde O(n|\mathcal P|)$ | 少于该轮数无法近最优 |

- 随机化“发挥作用”的临界点是第三轮：2 轮时随机化不能超越确定性算法；3 轮时即可达到常数轮近最优。
- 未知 $k$ 时随机化只需比已知 $k$ 多 1 轮；而确定性算法需要多 $O(\log n)$ 倍轮数，随机化与确定性的分离更加显著。
- 弱子集查询同样可以利用随机化将轮数压缩到 3/4 轮，查询复杂度为 $\tilde O(nk/s^2)$。
