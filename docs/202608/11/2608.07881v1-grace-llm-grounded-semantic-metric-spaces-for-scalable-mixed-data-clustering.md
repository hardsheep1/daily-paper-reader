## 摘要
混合表格数据的聚类需要一个统一的度量空间，以弥合连续数值测量与离散分类符号之间的固有异质性。传统上，算法完全依赖数据集内部统计量来估计分类关系，这将学习到的度量限制在经验共现上，忽略了概念上明显但统计上未观察到的相似性。尽管LLM提供了外部世界知识，但将其以文本为中心的推理应用于高度抽象的表格概念面临重大挑战。弥合这种模态差距以构建语义完整的度量通常需要将LLM嵌入迭代度量学习循环中，以动态优化跨模态表示。这会产生难以处理的计算开销，迫使在语义丰富性和可扩展性之间做出妥协。因此，我们提出了GRACE，一个基于LLM的可扩展混合数据聚类框架。GRACE通过多视角LLM查询策略将语义获取转移到属性-值级别，将异构值映射为知识信息描述。关键在于，这种一次性基础化提取了通用语义表示，将异构属性嵌入统一空间，将昂贵的LLM调用与迭代优化解耦。此外，GRACE将这些外部语义与数据集内部统计证据进行交叉验证，以确保与特定数据集的聚类结构对齐。最终，GRACE在匹配传统统计驱动基线可扩展性的同时，在11种竞争方法中实现了更优的聚类准确性和概念可解释性。源代码可在https://github.com/develop-yang/GRACE-GRACE-A获取。

## Abstract
Clustering mixed tabular data requires a unified metric space to bridge the inherent heterogeneity between continuous numerical measurements and discrete categorical symbols. Traditionally, algorithms rely entirely on dataset-internal statistics to estimate categorical relationships, which confines the learned metric to empirical co-occurrences and ignores conceptually obvious yet statistically unobserved affinities. Although LLMs offer external world knowledge, applying their text-centric reasoning to highly abstract tabular concepts presents significant challenges. Bridging this modality gap to construct a semantically complete metric typically requires embedding LLMs into iterative metric learning loops to dynamically optimize cross-modality representations. This incurs intractable computational overhead, forcing a compromise between semantic enrichment and scalability. Therefore, we propose GRACE, an LLM-grounded framework for scalable mixed-data clustering. GRACE shifts semantic acquisition to the attribute-value level via a multi-perspective LLM querying strategy, mapping heterogeneous values into knowledge-informed descriptions. Crucially, this one-shot grounding extracts general-purpose semantic representations that embed heterogeneous attributes into a unified space, decoupling expensive LLM invocation from iterative optimization. Furthermore, GRACE cross-validates these external semantics against dataset-internal statistical evidence to ensure alignment with the dataset-specific cluster structure. Ultimately, GRACE matches the scalability of conventional statistics-driven baselines while achieving superior clustering accuracy and conceptual interpretability over 11 competing methods. The source code is available at https://github.com/develop-yang/GRACE-GRACE-A

## 1. 核心问题与整体含义（研究动机与背景）

混合表格数据广泛存在于医疗、金融、电商等真实场景中，其聚类任务面临一个根本性挑战：**如何统一测量数值属性与分类属性之间的相似度**。

- **分类属性缺乏固有距离**："nurse"与"doctor"的符号形式本身不携带度量信息，其语义距离必须从外部引入或从数据中推断。
- **传统方法完全依赖数据集内部统计**：无论是特征空间中的距离函数（熵加权、交叉属性耦合、高阶值交互图）还是表示学习方法，其学习信号均来自观测数据的共现、依赖或交互模式。这导致一个**固有盲区**——任何在观测样本中未留下统计痕迹的概念性关联都无法被恢复。例如，两个从未共现的取值，即使领域知识明确表明它们相近，统计方法也会将其判为远距。
- **LLM提供了外部世界知识，但引入存在效率瓶颈**：LLM编码了真实世界概念与关系的先验知识，但将LLM嵌入迭代式度量学习或聚类优化循环会带来难以承受的延迟与计算开销——尤其是在邻域结构随数据规模膨胀时。
- **文本中心范式与表格数据不匹配**：现有LLM聚类方法主要面向天然文本输入（句子、文档），而表格数据中的分类符号是离散的、语义高度浓缩的概念，数值是带有自身度量结构的可计算量，两者无法直接套用文本范式。

**核心问题**：如何在引入LLM世界知识来丰富混合数据聚类语义的同时，避免将LLM嵌入迭代优化循环所导致的计算瓶颈，实现可扩展且语义完整的聚类度量空间？

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

GRACE采用四阶段流程：**问题形式化 → LLM基础属性描述 → 双视图邻域一致性 → 模型训练与谱聚类**。核心设计哲学是**将语义获取从实例/样本对级别转移到属性-值级别**，实现一次性语义注入，从而将昂贵的LLM调用与聚类时的迭代优化彻底解耦。

### 2.2 关键技术细节

**（1）4P多视角知识提取模板**

对每个属性值，GRACE通过一个结构化提示模板（4P）让LLM生成描述，包含四个互补视角：

- **t_CORE（定义视角）**：该值的基本含义
- **t_IND（功能视角）**：该值隐含的功能关联
- **t_PAT（上下文视角）**：该值在何处共现
- **t_DIS（区分视角）**：该值如何与同类其他值区分

模板还包含**领域自适应角色分配**与**质量约束**（要求具体、无行话、含领域示例）。四部分拼接成单段多面描述，为下游编码提供丰富语义基础。

**（2）数值属性的LLM委托离散化**

对数值属性，GRACE让LLM基于属性名、观测范围和领域背景自行决定划分区间数量与边界——例如胆红素按肝病学标准阈值分为正常（<1.2 mg/dL）、升高（1.2–3.0）、严重（>3.0）。区间同样通过4P模板生成描述，使分类值与非数值区间共享统一文本格式。

**（3）编码与相似度计算**

- 每个属性-值描述经Transformer编码器 f_θ 映射为密集嵌入 e(j,o)（式4）
- 样本表示由各属性嵌入**拼接**而成：z_i = e(1,oⁱ₁) ⊕ e(2,oⁱ₂) ⊕ ... ⊕ e(m,oⁱₘ)（式5）
- 语义相似度采用**余弦相似度**（式6）

**（4）双视图邻域一致性验证**

- **语义视图**（主视图）：由LLM描述构建的相似度矩阵 S_sem
- **统计视图**（验证视图）：参数无关编码——分类值用one-hot基向量，数值做min-max归一化，拼接后计算余弦相似度 S_stat（式7）
- **自然邻居（NaN）图**：通过相互约束条件（双方互认为邻居）提取两视图的局部邻域结构（式8–9）
- **邻域一致性分数**：Γ_ij = NN_sem · NN_stat（式10），两视图均确认的邻域对被视为高置信度
- **亲和度精化**：ρ_il = S_sem · α_il，其中 α_il = 1 + Γ_il（式11–12）。未确认对保持原语义值，确认对按比例增强——**统计证据增强而非覆盖外部语义**

**（5）谱聚类与图稀疏化**

- 以REQ（相对特征间隙质量）为目标，在最小化图碎片化的候选阈值中选取最优稀疏化阈值 θ*（式15）
- 对稀疏邻接矩阵提取K个最小特征向量，行归一化后做k-means

**（6）近似变体GRACE-A**

为突破标准GRACE的O(n³)时间/O(n²)空间限制，GRACE-A采用**最远点采样的锚点二分图**，将样本仅连接到p个锚点（p≪n），以Nyström方式恢复谱分量，复杂度降至**O(np(md_e + p))时间和O(n(md_e + p))空间**，对固定p呈线性增长。

### 2.3 算法流程

```
1. 对每个属性：LLM生成值级描述（分类值逐值生成；数值属性先LLM离散化再生成）
2. 用InfoNCE损失微调编码器 f_θ（同一文本用不同dropout掩码作为正例）
3. 拼接属性嵌入得到样本语义表示，计算语义相似度
4. 构建统计特征，计算统计相似度
5. 构建两视图的自然邻居图，计算一致性矩阵 Γ
6. 通过分层增强精化亲和度矩阵
7. 对候选阈值评估REQ，选最优稀疏化阈值
8. 归一化谱聚类得到最终簇划分
```

## 6. 主要结论与发现

1. **GRACE在22个数据集的几乎所有指标上排名第一**：分类数据集ARI平均排名1.15/12，混合数据集ARI平均排名1.18/7，领先于所有非LLM和LLM基线。
2. **LLM语义+统计验证的组合是关键**：单一语义表示（SR）将平均排名从约2.6降至1.9；增加双视图一致性（DVNC）进一步降至约1.5。DVNC在SH数据集上将ARI从0.068提升至0.294（语义表示单独无增益）。
3. **双属性语义接地优于单属性**：分类和数值属性同时接地时平均排名最低（1.20），单调递减趋势证实统一语义度量空间的价值。
4. **近似变体GRACE-A保持竞争力**：在22个数据集上与GRACE并列前二，在最大规模（100K样本）时甚至因锚点采样的隐式正则化而略优。
5. **对LLM后端选择高度稳健**：更换GPT为Claude/DeepSeek/Gemini后，ARI偏差大多在±0.02内，Friedman检验p=0.41/0.96（不显著），证明增益源于4P提示设计和交叉验证而非特定模型。
6. **语义接地恢复真实结构**：在CK案例中，GRACE从未被明确告知序数信息，却通过语义推理自然恢复了血清肌酐五个严重级别从正常到危急的平滑梯度——这是纯统计方法（HARR将mild与moderate完全混淆）无法实现的。
7. **可扩展性**：GRACE-A在RTX 3060上处理100K样本呈近似线性扩展，而所有密集谱方法在约20K样本时即内存溢出。

## 7. 优点与亮点

- **范式创新**：将LLM辅助度量学习从"迭代优化循环"重构为"一次性值级接地+无LLM度量适配"，从根本上解决效率瓶颈——语义获取成本随值基数而非样本量增长
- **理论完备**：提供四个复杂度定理（GRACE/GRACE-A的时间和空间界），并有补充材料中的后验概率论证支持双视图确认的证据价值
- **设计精巧的4P提示**：通过定义/功能/上下文/区分四视角，解决了朴素提示导致的嵌入塌缩问题，并统一了分类值与数值区间两种异构属性的描述格式
- **非对称双视图设计**：语义视为主、统计视图只做选择性验证（增强而非覆盖），核心"1+Γ"乘法机制在保留外知识信号的同时修正错误联想，在SH（图碎片化风险高）和ZO（语义幻觉）上展现出修复能力
- **鲁棒性论证充分**：Remark 1证明了值级嵌入+拼接设计对关键词错位的鲁棒性（属性内一致对共享值身份锚点）；Remark 2阐明了非对称视图的设计哲学
- **代码开源**，可复现性有保障

## 8. 不足与局限

### 方法层面

- **标准GRACE计算开销高**：O(n³)时间/O(n²)空间仅适用于中等规模数据，大规模场景必须依赖近似变体GRACE-A
- **值级地接的静态性**：外部语义在离线阶段固定后不再随数据分布变化更新，对概念漂移或新类别出现无法自适应
- **依赖属性值可枚举性**：数值属性需先通过LLM离散化，若LLM划分的区间边界与实际分布严重不一致，可能丢失数值属性的精细度量结构（如微小但重要的数值差异被归入同一区间）
- **文本描述的信息瓶颈**：LLM描述的质量直接决定上限——描述不完整或带有偏见（gender/race等敏感属性上的刻板印象）会系统性扭曲语义空间

### 实验层面

- **数据集规模有限**：最大约为5万样本，缺少真实大规模表格基准的验证
- **效率比较缺实测**：未定量比较GRACE与LLM基线（如ClusterLLM）的token消耗和时间开销，"低开销"主张缺少直接证据
- **合成数据泛化性存疑**：可扩展性测试的合成数据来自单数据集的条件采样，簇结构规整，不能代表真实大数据的噪声与复杂性
- **K值敏感性**：未报告不同K值下的性能表现，真实场景中K通常

### 其他局限

- **时间与能耗报告缺失**：论文未披露LLM调用的总token消耗、墙钟时间或能耗数据，使得"低成本"主张停留在理论复杂度层面，难以被同行直接量化评估。
- **缺少失败案例分析**：仅在SH、ZO上提及语义幻觉与图碎片化问题，但未系统列出GRACE在哪些数据集上劣于基线（如是否在低基数、弱语义属性占主导的数据上有退化），对方法适用边界的刻画不够清晰。
- **多模态大模型未纳入**：未比较图像、文本之外的表格表示策略（如TableTransformer、GNN-based方法），GRACE与专门的表格预训练模型之间的定位关系不明确。

## 9. 综合评价

GRACE是一项设计清晰、验证充分的研究，其价值可从三个层面定位：

- **问题定位层面**：它准确识别了混合数据聚类的核心瓶颈——分类值与数值无法在统一度量空间中比较——并给出了一个基于LLM世界知识的优雅解答。将语义获取从实例对级上移到属性-值级，是解决"LLM×聚类"效率矛盾的关键洞察。
- **方法论层面**：双视图邻域一致性机制（统计视图作为选择性验证器而非竞争者）体现了克制而精妙的设计哲学——外部知识注入内部统计证据，而非互相取代。4P提示模板将异构属性统一为同质文本描述，是具有普遍适用性的工程贡献。
- **实证层面**：22个数据集、16个基线、4个LLM后端、多组消融与稳健性实验构成的证据链，使结论具有较强的可信度；近似变体GRACE-A将适用规模扩展到100K样本，回应了可扩展性质疑。

**总体判断**：GRACE在"LLM辅助表格聚类"这一新兴方向上做出了系统性贡献，其范式思路（值级一次性语义接地+统计交叉验证）比具体性能数字更有长远价值。但标准版的O(n³)复杂度、值级语义的静态性以及对LLM描述质量的依赖，使其距离生产级通用工具仍有距离。论文的完整实验设计（尤其是防泄漏与LLM稳健性验证）可作为同类研究的参照范式。

**一句话概括**：GRACE证明了——当外部世界知识与内部统计证据通过"非对称双视图一致性"机制系统性融合时，混合表格数据的语义聚类可以在不牺牲可扩展性的前提下获得显著且稳健的提升。
