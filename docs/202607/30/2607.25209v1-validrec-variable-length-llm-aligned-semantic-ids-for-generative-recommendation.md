## 摘要
生成式推荐通常使用通过聚类和量化构建的固定长度语义标识符（SIDs）来表示项目。然而，这些人工编码可能过度压缩项目语义，与预训练LLM词汇表不对齐，并且需要昂贵的自回归解码。鉴于此，我们提出VaLiDRec，一种基于变长、LLM对齐语义标识符的生成式推荐框架。VaLiDRec通过词元重要性估计、语义质量感知剪枝和冲突感知精炼，直接从信息丰富的原生LLM词汇表词元构建SID，使得标识符长度能够适应项目语义复杂度。为了建模用户偏好，VaLiDRec结合了图感知软提示，并将推荐重新表述为带有词元级项目评分的词元集预测，从而消除了自回归SID生成和束搜索。在四个真实世界数据集上的实验表明，VaLiDRec在所有评估指标上始终优于强序列推荐和生成式推荐基线。它进一步实现了优越的零样本冷启动项目性能，并且推理速度比LC-Rec快87.49倍。这些结果表明，LLM原生的变长语义标识符为生成式推荐提供了一种更具表达力和效率的范式。

## Abstract
Generative recommendation commonly represents items using fixed-length semantic identifiers (SIDs) constructed through clustering and quantization. However, these artificial codes may overcompress item semantics, remain misaligned with pretrained LLM vocabularies, and require costly autoregressive decoding. In light of this, we propose VaLiDRec, a generative recommendation framework based on variable-length, LLM-aligned semantic identifiers. VaLiDRec constructs SIDs directly from informative native LLM vocabulary tokens via token importance estimation, semantic-quality-aware pruning, and collision-aware refinement, allowing identifier lengths to adapt to item semantic complexity. To model user preferences, VaLiDRec incorporates graph-aware soft prompts and reformulates recommendation as token-set prediction with token-level item scoring, eliminating autoregressive SID generation and beam search. Experiments on four real-world datasets show that VaLiDRec consistently outperforms strong sequential and generative recommendation baselines across all evaluation metrics. It further achieves superior zero-shot item cold-start performance and 87.49$\times$ faster inference than LC-Rec. These results demonstrate that LLM-native variable-length semantic identifiers provide a more expressive and efficient paradigm for generative recommendation.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：生成式推荐（Generative Recommendation）通常使用固定长度的语义标识符（Semantic Identifiers, SIDs）来表示物品。这些 SIDs 通过聚类或量化（如 RQ-VAE、FSQ）将物品编码为离散序列。
- **现有缺陷**：
    1. **语义过压缩**：量化获取的编码是人工的、无显式语义的离散码，可能过度压缩物品语义，且与预训练 LLM 的词汇表不对齐。
    2. **固定长度不灵活**：所有物品使用相同长度的 SID，忽略语义复杂度的差异，简单物品和复杂物品被分配相同的表示容量。
    3. **解码效率低**：现有方法采用自回归解码 + 束搜索（beam search）来生成 SID，解码步数与 SID 长度 × 束宽成正比，计算开销大。
- **整体含义**：VaLiDRec 旨在提出一种**变长、与 LLM 词汇表自然对齐**的 SID 构建方式，并设计**并行 token 集预测**的推荐框架，从而在保持语义表现力、可控性的同时显著提升推理效率。

## 2. 方法论

- **核心思想**：利用预训练 LLM 的原生词汇表，直接从物品元数据文本中挑选出重要、有区分度的 token 组成 SID（变长、无顺序依赖），避免人工量化编码；然后通过**图感知软提示**注入协同信号，将推荐转化为**token 集并行预测**任务，消除自回归生成。

- **关键技术细节**：

  - **Stage 1: LLM-Native SID 构建**
    1. **Token 重要性评分**：对物品元数据文本经 LLM tokenizer 后的每个 token，结合其最终层隐藏层向量的范数（$\|h_{j,i}\|_2$）和逆文档频率（IDF）计算得分 $s_{j,i} = \|h_{j,i}\|_2 \cdot (\text{IDF}(t_{j,i}) + 1)$。同时结合 IDF 和隐藏层范数构建候选池。
    2. **贪婪剪枝**：以物品元数据语义向量 $\mathbf{e}_j$ 为参考，计算保留 token 集合 $\mathcal{R}_j$ 的语义质量 $Q(\mathcal{R}_j) = \cos(\mathbf{e}(\mathcal{R}_j), \mathbf{e}_j)$。迭代移除使 $Q$ 下降最小的 token（同时引入删除得分 $D_j(i)$ 平衡 IDF 惩罚），直至长度满足 $[L_{min}, L_{max}]$ 且 $Q$ 不低于阈值 $\tau$，从而实现变长。
    3. **冲突处理**：若不同物品得到相同语义 SID，则进行碰撞感知扩展（添加候选池中未被使用的、IDF 高/重要性高的 token），或替换权重最低的 token。对最终仍碰撞的物品，添加基于训练交互频率的辅助后缀标签（$\langle\text{SUF}_r\rangle$）用于唯一识别（不参与语义计算）。

  - **Stage 2: Graph-Prompted LLM for Token-Set Prediction**
    1. **图感知软提示**：利用物品 SID 的平均嵌入初始化物品表示，构建用户交互物品的转移图，使用两层 GraphSAGE 聚合邻居信息，再经 recency-weighted pooling 得到用户历史表示 $\mathbf{r}_u$，投影为 $P$ 个连续提示嵌入（软提示）拼接至序列前。
    2. **LLM 微调**：使用 LoRA 微调 LLM（Llama-3.2-1B），输入为“图感知软提示 + 序列化的历史物品 SID”。冻结其他所有词嵌入，仅更新 SID 相关 token 的梯度。
    3. **训练目标**（联合优化三个损失）：
       - **Token 集预测损失 $\mathcal{L}_{\text{token}}$**：二分类交叉熵，正样本为目标 SID 中的 token，负样本为当前 batch 中其他 SID 的 token。
       - **物品排序损失 $\mathcal{L}_{\text{rank}}$**：对每个用户，将预测 token 概率平均得到物品得分，采用 cross-entropy 区分正负物品。
       - **物品对比损失 $\mathcal{L}_{\text{item}}$**：InfoNCE 损失，对齐用户表示 $\mathbf{h}_u$ 与图增强的目标物品表示。
    4. **并行 Token 级物品评分**：单次 LLM 前向即可得到所有语义 token 的预测概率 $p_{u,t}$，按物品 SID 的平均概率 $q_{u,j} = \frac{1}{|S_j|} \sum_{t\in S_j} p_{u,t}$ 得到物品相关度，长度归一化防止偏长。
    5. **后缀打平**：若存在相同语义 SID 的物品，按辅助后缀排名决定次序，不影响其他物品排序。

- **公式/算法流程（文字说明）**：参见上述步骤，其中 Token 重要性评分、贪婪剪枝、删除得分 $D_j(i)$、语义质量 $Q$、碰撞扩展算法、三个损失函数 $\mathcal{L}_{\text{token}}$, $\mathcal{L}_{\text{rank}}$, $\mathcal{L}_{\text{item}}$ 以及最终物品得分 $q_{u,j}$ 在论文中均有详细公式。

## 7. 优点

- **方法新颖性**：首次直接从 LLM 原生词汇表构建变长 SID，避免了量化编码的语义失真和与 LLM 不对齐问题。
